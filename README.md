# ChatGPT Profile Manager for Mac

ChatGPTデスクトップアプリのCodexビューを、複数のChatGPTアカウントで使い分けるためのmacOS用ヘルパーアプリです。

## 現在のバージョン

**1.0.0**（macOS 14以降）

## ダウンロード

- [ChatGPT Profile Manager 1.0.0（macOS）](outputs/ChatGPT-Profile-Manager-macOS.zip)
- [ソースコード](outputs/ChatGPT-Profile-Manager-Source.zip)

## 主な機能

- アカウントを任意の数登録
- 登録時に、現在の既存環境へ紐づけるか新規分離プロファイルにするかを選択
- 既存環境へ紐づけられるアカウントは1つだけ。紐づけ確定後の追加アカウントは分離プロファイル
- アカウント名の変更
- 行のドラッグ＆ドロップによる並び替え（順序は保存）
- 分離プロファイルの削除（ゴミ箱へ移動）
- 紐づけを誤った場合の復旧導線
- アプリ内の「このアプリの仕組み」ガイド

## 使い方

1. `ChatGPT Profile Manager.app` を起動します。
2. 「アカウントを追加…」から任意の表示名を入力します。メールアドレスでなくても構いません。
3. 最初のアカウント、または既存環境が未割り当ての間に追加するアカウントでは、既存環境へ紐づけるか確認します。
4. 一覧の「開く」を押すと、実行中のChatGPTデスクトップアプリ（Codex）を通常終了して、選択した環境で再起動します。

分離プロファイルを初めて開いたときは、そのプロファイルで使用するChatGPTアカウントにログインしてください。

## 既存環境と分離プロファイル

既存環境へ紐づけたアカウントは、現在のCodex環境をコピーせず、そのまま使用します。既存のプロジェクト、チャット、設定、ログイン情報は移動されません。

それ以外のアカウントは、次の2つをアカウントごとに分離します。

- `CODEX_HOME`：Codexの設定、認証、セッション、ログ、スキルなど
- `CODEX_ELECTRON_USER_DATA_PATH`：ChatGPTデスクトップアプリ側のCookie、ログイン状態、アプリデータ

分離プロファイルの保存先は次のとおりです。

`~/Library/Application Support/Codex Account Switcher/Profiles/`

アプリ名変更後も、既存データとの互換性を保つため保存フォルダの内部名は従来のままです。

## 削除と復旧

### 分離プロファイルの削除

「削除…」を実行すると、対象の分離プロファイルと登録情報をゴミ箱へ移動します。必要であればFinderのゴミ箱から復元できます。実行前にCodexを終了してください。

既存環境へ紐づいたアカウントは削除できません。既存のプロジェクトやチャットを保護するためです。

### 紐づけを間違えた場合

メイン画面の「既存環境の紐づけを誤った場合…」から、ChatGPT Profile Manager上の登録だけを外せます。

- 既存環境のプロジェクト、チャット、設定、ログイン情報は削除・変更しません
- 他の分離プロファイルも削除・変更しません
- 次のアカウント追加時に、紐づけるか再び確認できます

通常画面から、紐づけ先を直接変更することはできません。

## 注意事項

- 切り替え前に、実行中のローカルタスクがないことを確認してください
- Codexが10秒以内に通常終了しない場合は、強制終了せずエラーを表示します
- 複数アカウントを使うときは、普段のChatGPT／Codexアイコンではなく、このアプリの「開く」から起動してください
- このアプリはOpenAI公式機能ではありません
- アカウントの利用上限を回避する目的では使用しないでください

## 開発とビルド

```sh
swift test
swift build -c release
```

配布用アプリ（ad-hoc署名付き）は次のスクリプトで生成できます。

```sh
./package-app.sh
```

署名・公証された公式配布アプリではなく、ローカルで使用する補助ツールです。
