# Code of Conduct / 行動規範

ChatGPT Profile Manager is maintained as a small, practical open-source
project. Keep discussions respectful, specific, and useful to people who use
or contribute to the project.

ChatGPT Profile Managerは、小規模で実用的なオープンソースプロジェクトとして
運営しています。利用者や貢献者にとって有益になるよう、敬意を持ち、具体的で、
建設的なコミュニケーションを心がけてください。

## Expected behavior / 期待される行動

- Be respectful and constructive, including when you disagree.
- Describe reproducible behavior and practical trade-offs.
- Respect different backgrounds, experience levels, and opinions.
- Remove or redact private data before sharing logs, screenshots, or examples.

- 意見が異なる場合も、相手を尊重し建設的に話し合う。
- 再現手順や具体的な影響を示して議論する。
- 異なる背景、経験、意見を尊重する。
- ログ、スクリーンショット、例を共有する前に個人情報や機密情報を削除する。

## Unacceptable behavior / 許容されない行動

Harassment, discrimination, personal attacks, threats, spam, doxxing, and
deliberately disruptive behavior are not acceptable. Never post another
person's passwords, tokens, `auth.json`, cookies, account identifiers, private
logs, or unredacted profile data. Security vulnerabilities must be reported
privately as described in [SECURITY.md](SECURITY.md), not in a public issue.

嫌がらせ、差別、個人攻撃、脅迫、スパム、晒し行為、意図的な妨害は禁止します。
他人のパスワード、トークン、`auth.json`、Cookie、アカウント識別子、非公開ログ、
未加工のプロファイルデータを投稿しないでください。脆弱性は公開Issueではなく、
[SECURITY.md](SECURITY.md)の手順で非公開に報告してください。

## Moderation / 対応

The maintainer may edit, hide, or remove content that violates this code of
conduct, and may close discussions that cannot be brought back to a
constructive topic. For non-security concerns, use a GitHub issue or contact
the maintainer through the GitHub profile. For security concerns, follow
[SECURITY.md](SECURITY.md).

メンテナーは、この行動規範に違反する内容を編集、非表示、削除し、建設的な議論に
戻せない場合は議論を終了することがあります。セキュリティ以外の問題はGitHub Issue
またはメンテナーのGitHubプロフィールから連絡してください。セキュリティの問題は
[SECURITY.md](SECURITY.md)を使用してください。
