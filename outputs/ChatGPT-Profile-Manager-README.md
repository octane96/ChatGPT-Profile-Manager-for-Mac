# ChatGPT Profile Manager for Mac

ChatGPTデスクトップアプリのCodexビューを、複数のChatGPTアカウントで使い分けるためのmacOS用ヘルパーアプリです。

## 現在のバージョン

**1.0.0**（macOS 14以降）

## ダウンロード

- [ChatGPT Profile Manager 1.0.0（macOS）](outputs/ChatGPT-Profile-Manager-macOS.zip)
- [ソースコード](outputs/ChatGPT-Profile-Manager-Source.zip)

## 主な機能

- アカウントを任意の数登録
- 既存環境がある場合、初回起動時にメールアドレスを表示名として自動登録
- アカウント追加時に、ChatGPTの既存環境・新しい分離プロファイル・既存の分離プロファイルから使う保存先を選択
- ChatGPTの既存環境へ紐づけられるアカウントは1つだけ。紐づけ確定後の追加アカウントは分離プロファイル
- アカウント名の変更
- 行のドラッグ＆ドロップによる並び替え（順序は保存）
- 既存の分離プロファイルを保存先として登録
- 分離プロファイルの登録削除（保存フォルダは保持）
- アカウント一覧にプラン名を表示
- アカウント一覧に5時間枠・週間枠の残り率とリセット時刻を表示
- アプリ内の「仕組みを見る」ガイド
- 初回起動時の「仕組みを見る」チュートリアル表示
- Macの言語設定に合わせた日本語・英語表示
- 設定画面から表示言語を「Macの設定に従う」、「日本語」、「English」で切り替え
- 異なるプロファイルのChatGPTを同時に起動
- 起動中プロファイルの表示と、同じ保存先の二重起動防止
- 起動中プロファイルのChatGPTを「終了」から個別に終了
- プロファイル間の設定コピー（バックアップ付き）
- 複数プロファイル間の設定共有グループ
- 共有設定の解除と現在設定の保持
- 分離プロファイルごとの起動アプリ生成

## 使い方

1. `ChatGPT Profile Manager.app` を起動します。
2. 初回起動時は「このアプリの仕組み」が表示されます。ページを確認して「完了」を押してください。
3. 既存環境がある場合は、最初のアカウントがメールアドレスを表示名として自動登録されます。既存環境がない場合は、「アカウントを追加」から任意の表示名を入力します。
4. 2件目以降を追加する場合は、「アカウントを追加」から名前を入力し、「このアカウントで使う保存先を選択」で保存先を選びます。「ChatGPTの既存環境を使う」、「新しい分離プロファイルを作る」、「既存の分離プロファイルを使う」から選べます。
5. 既存の分離プロファイルを使う場合は、一覧から保存先ディレクトリを選びます。登録されていない既存フォルダの登録も、同じ選択画面から行えます。フォルダのコピーや移動は行いません。
6. 一覧の「起動」を押すと、他のChatGPTを終了せず、選択したプロファイルを別インスタンスとして起動します。同じ保存先は複数起動できません。起動中の行ではボタンが「終了」に変わり、確認後にそのプロファイルのChatGPTだけを終了できます。
7. アカウント行の「設定」から「設定を共有」または「設定をコピー」を選べます。「設定を共有」は複数プロファイルで継続的に同じ設定を使い、「設定をコピー」はその時点の設定だけを複製します。設定変更時は対象プロファイルのChatGPTを終了してください。
8. 分離プロファイルの行にある「起動アプリを作成」を押すと、プロファイル専用の起動アプリを作成します。Finderで表示された起動アプリをDockへドラッグすると、そのプロファイルを直接起動できます。「起動アプリを更新」は表示名やアイコンを更新します。ChatGPTの既存環境にはChatGPTアプリ自身のDock機能があるため、このボタンは表示されません。

分離プロファイルを初めて起動したときは、そのプロファイルで使用するChatGPTアカウントにログインしてください。

## 表示言語

初期設定は「Macの設定に従う」です。Macの言語設定で最も優先されている言語が日本語の場合は日本語、それ以外の場合は英語で表示します。「管理」の「設定」から日本語またはEnglishを明示的に選ぶこともでき、変更はすぐに画面へ反映されます。表示言語が変わっても、登録済みのアカウント名、プロファイルの保存先、データは変更されません。

## 環境の種類と紐づけの違い

このアプリでは、保存先を「環境」として管理します。ChatGPTの既存環境と分離プロファイルは別のものです。アカウント追加時は、両者を同じ「使う保存先」の選択画面で比較できます。

| 種類・操作 | 意味 |
| --- | --- |
| ChatGPTの既存環境／「ChatGPTの既存環境を使う」 | ChatGPTが普段使っている既定の保存先を、アカウント一覧の1アカウントに割り当てます。既存のプロジェクト、チャット、設定、ログイン状態はそのままです。 |
| 新しい分離プロファイル／「新しい分離プロファイルを作る」 | ChatGPT Profile Managerが、そのアカウント専用の保存先を新しく作ります。 |
| 既存の分離プロファイル／「既存の分離プロファイルを使う」 | すでに`Profiles`フォルダにある分離プロファイルを、アカウント一覧へ登録します。フォルダのコピーや移動は行いません。 |

上の選択は、同じ画面で保存先を比較しながら選べるようにしています。「ChatGPTの既存環境を使う」は既存環境をアカウントに割り当て、「既存の分離プロファイルを使う」は既存フォルダを一覧に登録します。

### ChatGPTの既存環境

ChatGPTの既存環境へ紐づけたアカウントは、現在のChatGPT環境をコピーせず、そのまま使用します。既存のプロジェクト、チャット、設定、ログイン情報は移動されません。既存環境へ紐づけられるアカウントは1つだけです。

### 分離プロファイル

既存環境へ紐づけなかったアカウントは、アカウントごとに分離プロファイルを使います。分離プロファイルでは、次の2つをアカウントごとに分けます。

- `CODEX_HOME`：Codexの設定、認証、セッション、ログ、スキルなど
- `CODEX_ELECTRON_USER_DATA_PATH`：ChatGPTデスクトップアプリ側のCookie、ログイン状態、アプリデータ

分離プロファイルの保存先は次のとおりです。新しく作成する場合は `account-表示名-短いID` の形式でディレクトリを作るため、Finderでもアカウントを見分けられます。既存のディレクトリ名は変更せず、そのまま登録して使えます。

`~/Library/Application Support/ChatGPT Profile Manager/Profiles/`

## 設定の共有とコピー

アカウント行の「設定」から、次の2つの操作を利用できます。

| 操作 | 動作 |
| --- | --- |
| 設定を共有 | アプリ管理下の共有グループを作り、参加プロファイルが同じ設定を参照します。共有グループは特定のアカウントを親にしません。 |
| 設定をコピー | コピー元からコピー先へ通常ファイルとして一度だけ複製します。コピー先の既存設定はバックアップされます。 |

対象はCodexのローカル設定です。初期状態では`AGENTS.md`が選択され、`config.toml`、`rules`、`AGENTS.override.md`は必要に応じて選べます。`rules`はサンドボックス外のコマンド実行許可に影響するため、選択前に内容を確認してください。

認証情報、`auth.json`、セッション、ログ、SQLite索引、Cookie、`ElectronUserData`、ChatGPTのプロジェクトやチャットは共有・コピーされません。`config.toml`の共有は、認証情報、アカウント固有値、または共有対象外の項目が検出された場合は安全のため停止します。`config.toml`のコピーを選ぶ場合は、内容を確認してください。

共有グループとバックアップはプロファイル本体と別の場所に保存されます。

```text
~/Library/Application Support/ChatGPT Profile Manager/
├── Profiles/
├── Settings/
│   ├── SharedSettings/
│   └── Backups/
└── SettingsRegistry.json
```

共有解除時は共通設定をプロファイルへ実体化してからリンクを外すため、現在の設定は保持されます。プロファイルの登録だけを削除しても、設定共有グループや保存フォルダは削除されません。

## プロファイル起動アプリ

起動アプリは、分離プロファイルの保存先を指定してChatGPTを直接起動する専用の`.app`です。ChatGPTアプリが標準の場所にない場合は、互換用にChatGPT Profile Managerへ処理を引き継ぎます。別のプロファイルは並列起動できますが、同じ保存先を二重起動することはできません。ChatGPTの既存環境は対象外です。

起動アプリはプロファイル名を使った名前で、次の場所に保存されます。

```text
~/Library/Application Support/ChatGPT Profile Manager/Launchers/
└── ChatGPT <プロファイル名>.app
```

起動アプリごとにプロファイル名、色・頭文字付きのアイコンを生成します。頭文字はキャメルケースや空白・ハイフン・アンダースコアを単語の区切りとして抽出し、先頭2単語の頭文字を使います。そのため`ShareFair`、`share-fair`、`share_fair`はいずれも`SF`になります。単語が1つだけの場合は先頭2文字を使います。Dockへの追加はmacOSの仕様上、作成後にFinderからDockへドラッグして行います。アカウント名を変更した場合は、行の「起動アプリを更新」を押すと名前、表示名、アイコンを更新できます。

## 利用上限の表示

アカウント一覧には、各アカウントのCodex利用状況を次の2枠で表示します。

- 5H：直近5時間の利用枠
- 週間：週間の利用枠

利用状況を取得できた場合は、同じ行に現在のプラン名も表示します。

表示される割合は「残り」です。5Hは `残り XX% HH:MMにリセット`、週間は `残り XX% M月D日 HH:MMにリセット` の形式で、24時間表示します。利用できる上限リセットクレジットがある場合は、週間行の下に `上限リセットX件` と有効期限を表示します。複数件ある場合は期限を一行ずつ表示します。ラベルのツールチップでは使用済みの割合とリセット日時を確認できます。ローカルのCodexコマンドが見つからない場合、未ログインの場合、または通信できない場合は「—」と表示されます。認証情報や利用状況をChatGPT Profile Managerの設定へ保存することはありません。

## 削除について

### 分離プロファイルの登録削除

「削除」を実行すると、アカウントの登録情報だけを削除します。分離プロファイルの保存フォルダ、ログイン状態、設定、セッション、ログなどは残ります。後からアカウント追加時に「既存の分離プロファイルを使う」を選ぶと、同じ保存先を再登録できます。そのプロファイルが起動中の場合は、対応するChatGPTを終了してから実行してください。

既存環境へ紐づいたアカウントは削除できません。既存のプロジェクトやチャットを保護するためです。既存環境の紐づけは初回起動時に自動で確定し、後から変更する操作はありません。

## 注意事項

- 異なるプロファイルは並列起動できますが、同じプロファイルの二重起動はできません
- 一覧の「終了」は、確認ダイアログの後に対応するプロファイルのChatGPTだけを終了します
- ChatGPTを終了すると、対応するアカウントの「起動中」表示が解除されます
- 複数アカウントを使うときは、普段のChatGPT／Codexアイコンではなく、このアプリの「起動」から起動してください
- このアプリはOpenAI公式機能ではありません
- アカウントの利用上限を回避する目的では使用しないでください
