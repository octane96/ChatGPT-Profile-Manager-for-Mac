# ChatGPT Profile Manager

任意の数のChatGPTアカウントを、それぞれ分離したプロファイルで起動するmacOSアプリです。ChatGPTデスクトップアプリのCodexビューを通常のウィンドウとDockアイコンから操作し、メニューバーには常駐しません。

## 最初のアカウントを設定する

1. `ChatGPT Profile Manager.app` を起動します。
2. 「アカウントを追加…」から、ChatGPT Profile Managerで使用する任意の名前を入力します。
3. このMacで現在使用しているCodex環境と紐づけるか選びます。
   - 紐づける：既存のプロジェクト、チャット、設定、ログイン情報をコピーせず、そのまま使用します。
   - 紐づけない：新しい分離プロファイルを作成します。
4. 一覧の「開く」からアカウントを起動します。分離プロファイルでは、初回に対応するChatGPTアカウントでログインしてください。

アカウント名はメールアドレスに限定されません。「メイン」「開発チーム」など、分かりやすい任意の名前を使用でき、後から「名前を変更…」で変更できます。

## アカウントを追加する

- 既存環境がまだどのアカウントにも紐づいていない場合：追加のたびに、そのアカウントを既存環境と紐づけるか確認します。
- 既存環境が1アカウントへ紐づいている場合：以降に追加するアカウントは、すべて新しい分離プロファイルになります。
- 登録数に固定の上限はありません。一覧はスクロールできます。
- 一覧の行をドラッグ＆ドロップして並び替えられます。変更した順序は次回起動後も保持されます。

以後はChatGPT Profile Managerを起動し、一覧からアカウントを選ぶだけです。切替時には実行中のChatGPTデスクトップアプリ（Codex）を通常終了し、選択したプロファイルで再起動します。ChatGPT Profile Managerのウィンドウを閉じるとアプリ自体も終了します。

## 分離されるもの

- ChatGPT／Codexのログイン状態とCookie
- Codexの設定と認証
- ローカルセッション、ログ、スキルなどのCodex状態
- Chromium／Electron側のアプリ状態

分離プロファイルは次の場所へ保存されます。

`~/Library/Application Support/Codex Account Switcher/Profiles/`

既存データとの互換性を保つため、アプリ名変更後も保存フォルダの内部名は従来の `Codex Account Switcher` のままです。既存環境と紐づけた1アカウントは、通常版Codexのプロファイルと `~/.codex` をそのまま使用します。既存データの移動やコピーは行いません。それ以外のアカウントは、上記保存先にアカウント固有のディレクトリを持ちます。

## 仕組みを確認する

メイン画面の「このアプリの仕組み」から、既存環境との紐づけ、分離される保存先、切り替え、並び替え、削除、復旧の流れを確認できます。

## 分離プロファイルを削除する

登録済みアカウントの「削除…」を押し、確認画面で実行します。対象アカウントの分離プロファイルと登録情報はゴミ箱へ移動するため、必要ならゴミ箱から復元できます。削除前にCodexを終了してください。

既存環境に紐づいたアカウントは削除できません。既存のプロジェクト、チャット、設定、ログイン情報を保護するためです。紐づけを外す場合は、下記の復旧導線を使用してください。

## 既存環境との紐づけを間違えた場合

アプリ画面の「既存環境の紐づけを誤った場合…」を使用します。復旧操作は、Codexを終了してから実行してください。

- ChatGPT Profile Managerから、紐づけたアカウントの登録だけを外します。
- 既存環境のプロジェクト、チャット、設定、ログイン情報は削除・変更しません。
- 他のアカウントの分離プロファイルも削除・変更しません。
- 次にアカウントを追加すると、既存環境と紐づけるか再び確認します。

通常画面から既存環境の紐づけ先を直接変更することはできません。

## v1.3以前から更新する場合

従来の固定された2プロファイルは、初回起動時に「アカウント1」「アカウント2」へ自動移行します。既存環境への紐づけ、最後に使用したアカウント、`personal`／`work`プロファイルの実体ディレクトリはそのまま引き継ぎます。移行後は画面から任意の名前へ変更できます。

## 注意事項

- 切替前に、実行中のローカルタスクがないことを確認してください。
- Codexが10秒以内に通常終了しない場合、強制終了せずにエラーを表示します。
- プロファイルの削除は分離プロファイルだけが対象です。実行前に対象名と保存データの範囲を確認してください。
- 普段のCodexアイコンを直接開くと、分離されていない通常プロファイルが起動します。複数アカウント運用では本アプリの画面から起動してください。
- あるアカウントの利用上限に達した後、別アカウントで上限を回避する目的には使用しないでください。
- このツールはOpenAI公式機能ではありません。Codexデスクトップアプリの更新で起動方法が変更された場合は、追従修正が必要です。
